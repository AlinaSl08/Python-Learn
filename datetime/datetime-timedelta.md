# Тип данных datetime

✅ **Тип данных `datetime`**:

+ При создании новой даты-времени нужно указать год, месяц, день, часы, минуты, секунды и микросекунды. Год, месяц и день являются **обязательными**, а часы, минуты, секунды и микросекунды — **необязательными**.

``` python
from datetime import datetime

my_datetime = datetime(<year>, <month>, <day>, <hour>, <minute>, <second>, <microsecond>)
```
                  
+ Доступ к атрибутам:
``` python
my_datetime.year
my_datetime.month
my_datetime.day
my_datetime.hour
my_datetime.minute
my_datetime.second
my_datetime.microsecond
```
                  
✅ **Тип данных `datetime`** наследует весь функционал (атрибуты и методы) типа `date`.

✅ **Метод `combine()`** используется для создания нового объекта `datetime` из объектов `date` и `time`.

✅ **Методы `date()` и `time()`** используются для создания объектов `date` и `time` из объекта `datetime`.

✅ **Методы `now()` и `utcnow()`** используются для получения текущего локального и времени UTC соответственно.

✅ **Всемирное координированное время** (Coordinated Universal Time, UTC) — стандарт, по которому общество регулирует часы и время.

✅ **Начало эпохи** — это полночь 1 января 1970 года (00:00:00 UTC).

✅ **Метод `timestamp()`** позволяет преобразовать объект типа datetime в количество секунд, прошедших с момента начала эпохи. Данный метод возвращает значение типа float.

✅ **Метод `fromtimestamp()`** позволяет преобразовать количество секунд, прошедших с момента начала эпохи, в объект типа `datetime`.

✅ Для форматированного вывода объектов типов `date, time, datetime` используется один и тот же **метод `strftime()`**.

см. Таблица для форматирования даты и времени. (date-and-time.md)

✅ **Метод `strptime()`** преобразует строку (первый аргумент) в объект datetime согласно переданному формату (второй аргумент). При этом первый аргумент должен **соответствовать** формату второго аргумента.

✅ Тип данных `datetime` является **неизменяемым**.

✅ Объекты типа `datetime` можно **сравнивать** `(==, !=, <, >, <=, >=)`.

# Тип данных timedelta

✅ **Тип данных `timedelta`** представляет собой временной интервал (разницу между двумя объектами `datetime` или `date`) и используется для удобного выполнения различных манипуляций над типами `datetime` или `date`. При создании объекта `timedelta` можно указать следующие аргументы:

+ недели (`weeks`)
+ дни (`days`)
+ часы (`hours`)
+ минуты (`minutes`)
+ секунды (`seconds`)
+ миллисекунды (`milliseconds`)
+ микросекунды (`microseconds`)

✅ Тип `timedelta` внутренне хранит только сочетание `days, seconds, microseconds`, которые можно получить с помощью одноименных атрибутов:
``` python
my_delta.days
my_delta.seconds
my_delta.microseconds
```
                  
✅ **Метод `total_seconds()`** возвращает общее количество **секунд**, содержащееся во временном интервале `timedelta`.

✅ Временные интервалы (тип `timedelta`) можно **сравнивать** (`==, !=, <, >, <=, >=`).

✅ Тип данных `timedelta` поддерживает многие **математические операции**:

+ сложение временных интервалов
+ вычитание временных интервалов
+ умножение временного интервала на число
+ деление временного интервала на число
+ деление временного интервала на временной интервал

✅ **К объектам типа `datetime` и `date`** можно прибавлять (вычитать) **временные интервалы (тип `timedelta`)**, тем самым формируя новые объекты.

✅ Объект типа `timedelta` **возникает при вычитании** двух дат (тип `date`) или значений даты-времени (тип `datetime`).

✅ **Встроенные функции `str()` и `repr()`** можно использовать для преобразования типа `timedelta` к строковому типу.

✅ Тип данных `timedelta` является неизменяемым.
