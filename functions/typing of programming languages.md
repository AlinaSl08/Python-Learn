# Типизация языков программирования

✅ **Типизация языков программирования** ‌—‌ ‌это‌ ‌то,‌ ‌как‌ ‌различные‌ ‌языки‌ ‌распознают‌ ‌типы‌ ‌переменных.‌

✅ Языки‌ ‌программирования‌ ‌бывают‌:

+ нетипизированными‌ ‌(бестиповыми)
+ типизированными‌

✅ **Типизированные языки** подразделяются по нескольким параметрам:

+ статическая и динамическая типизация
+ сильная (строгая) и слабая (нестрогая) типизация
+ явная и неявная типизация

✅ Python — это язык с **динамической, сильной и неявной** типизацией.

✅ **Аннотации типов** представляют собой специальный синтаксис для объявления типов переменных, параметров функций и их возвращаемых значений.

✅ **Аннотирование функций:**
``` python
def func(arg: str) -> None:
    ...
```
                  
Если некоторый аргумент имеет значение по умолчанию:
``` python
def func(arg: str = 'beegeek') -> str:
    ...
```
                  
✅ **Аннотирование переменных:**
``` python
var: int = 5
```
                  
или:
``` python
var: int
var = 5
```
                  
✅ **Типы коллекций и их содержимое:**
``` python
список: list[int]                      # тип всех элементов списка
множество: set[float]                  # тип всех элементов множества
словарь: dict[str, int]                # тип ключей, тип значений
кортеж: tuple[str, bool, int]          # тип каждого элемента кортежа
```
                  
✅ **Атрибут `__annotations__`** позволяет получить доступ к использованным в функции аннотациям, которые представлены в виде словаря, где ключами являются названия параметров, а значениями – их типы. При этом возвращаемое функцией значение хранится в записи с ключом `return`.

✅ **Типы из модуля `typing`** позволяют работать с несколькими типами одновременно. Наиболее часто используемые типы модуля typing:

+ **`Union`** используется, когда значение может принадлежать одному из нескольких типов:
``` python
from typing import Union

number: Union[int, float]
```
                  
+ **`Optional`** указывает, что значение может быть либо заданного типа, либо None:
``` python
from typing import Optional

name: Optional[str]
```
                  
+ **`Any`** применяется, когда тип значения заранее неизвестен или может быть абсолютно любым:
``` python
from typing import Any

def func(arg: Any) -> Any:
    return arg
```
                  
+ **`NoReturn`** указывает, что функция никогда не возвращает значение:
``` python
from typing import NoReturn

def stop() -> NoReturn:
    raise RuntimeError('no way')
```
