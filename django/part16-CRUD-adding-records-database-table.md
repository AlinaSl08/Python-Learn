# Основы работы с ORM в Django (CRUD и консоли)

## Что такое CRUD и зачем нужен ORM?
**CRUD** — базовые операции с записями в базе данных:
* **C**reate — создание
* **R**ead — чтение
* **U**pdate — изменение
* **D**elete — удаление

**Преимущества Django ORM** (работы с БД через Python-классы вместо чистого SQL):
* Независимость кода от конкретной СУБД (легко сменить базу данных).
* Оптимизация скорости и количества запросов.
* Встроенная защита от SQL-инъекций.

## Создание записей (Create) через консоль Django

1. **Запуск стандартной консоли и импорт модели:**
   ```bash
   python manage.py shell
   ```
   ```python
   from women.models import Women
   ```

2. **Принцип «ленивых» моделей:**
   Создание экземпляра класса `Women` **не добавляет** запись в БД сразу — объект существует только в памяти. Реальная запись происходит только после вызова метода `.save()`.

3. **Способы создания и сохранения записи:**

   * **Способ 1 (сразу с аргументами):**
     ```python
     w1 = Women(title='Анджелина Джоли', content='Биография Анджелины Джоли')
     w1.save()  # Запись попадает в БД, объекту присваивается id (например, 1)
     ```
     *(Поля со значениями по умолчанию или автозаполнением, вроде `time_create` и `is_published`, указывать не обязательно).*

   * **Способ 2 (через пустой объект и атрибуты):**
     ```python
     w3 = Women()
     w3.title = 'Джулия Робертс'
     w3.content = 'Биография Джулии Робертс'
     w3.save()
     ```

4. **Полезные фишки и атрибуты объекта:**
   * `_` — в консоли хранит результат последней выполненной операции (`w1 = _`).
   * `w1.pk` (Primary Key) — универсальный атрибут для получения идентификатора записи (аналог `w1.id`, равен `None` до сохранения).
   * Просмотр выполненных SQL-запросов в стандартной консоли:
     ```python
     from django.db import connection
     connection.queries  # Выведет список словарей с ключами 'sql' и 'time'
     ```

## Улучшение консоли для удобной работы с ORM

### 1. Установка `ipython` (автодополнение кода)
Добавляет подсветку синтаксиса и автодополнение команд по нажатию клавиши `Tab` в стандартном `python manage.py shell`.
* **Установка:** `pip install ipython` (или через меню PyCharm: *File -> Settings -> Project -> Python Interpreter -> «+»*).

### 2. Установка `django-extensions` (расширенная консоль)
Пакет добавляет набор полезных команд для разработки, включая улучшенную консоль `shell_plus` (автоматически импортирует все модели проекта).

* **Установка:**
  ```bash
  pip install django-extensions
  ```
* **Подключение:** добавить `'django_extensions'` в список `INSTALLED_APPS` в файле `settings.py`.
* **Запуск консоли с автовыводом SQL-запросов:**
  ```bash
  python manage.py shell_plus --print-sql
  ```
