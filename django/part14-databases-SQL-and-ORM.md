# Модели (Models) и ORM в Django

**Модель (Model)** — это компонента паттерна проектирования MTV, отвечающая за хранение данных и работу с ними. 

* Django поддерживает 5 реляционных СУБД из коробки: **PostgreSQL, MariaDB, MySQL, Oracle и SQLite**.
* В реляционных БД данные хранятся в виде связанных таблиц: столбцы называются **полями** (определяют структуру), а строки с данными — **записями**.

---

## 1. Технология ORM (Object-Relational Mapping)

Вместо написания «сырых» SQL-запросов, которые отличаются в разных СУБД, в Django используется встроенная **ORM** (по принципу работы похожа на SQLAlchemy).

* **Универсальность:** программист описывает таблицы в виде обычных Python-классов, а Django сам переводит операции с ними в нужный диалект SQL.
* **Автоматизация:** фреймворк сам берет на себя открытие и закрытие соединений с базой данных при запросах пользователей.

---

## 2. Настройка подключения к БД (`settings.py`)

По умолчанию Django настроен на работу с легкой файловой СУБД **SQLite3**, которая не требует установки дополнительных драйверов. Настройки находятся в словаре `DATABASES`:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```
*(Для визуального просмотра и редактирования таблиц SQLite удобно использовать программу **DBSQLiteStudio** / Letos).*

## 3. Создание модели (`women/models.py`)

Модели приложения описываются в файле `models.py` в виде классов, унаследованных от базового класса **`models.Model`**. Атрибуты класса становятся столбцами (полями) таблицы в БД в том же порядке, в котором они объявлены.

### Пример модели `Women`:
```python
from django.db import models

class Women(models.Model):
    title = models.CharField(max_length=255)
    content = models.TextField(blank=True)
    time_create = models.DateTimeField(auto_now_add=True)
    time_update = models.DateTimeField(auto_now=True)
    is_published = models.BooleanField(default=True)
```

### Разбор полей и их параметров:

1. **`id` (Первичный ключ):**
   * Не прописывается вручную — Django **создает его автоматически** для каждой таблицы на основе базового класса `Model`.
2. **`CharField(max_length=255)`:**
   * Строковое поле ограниченной длины (для заголовков, имен). Параметр `max_length` является обязательным.
3. **`TextField(blank=True)`:**
   * Текстовое поле для больших объемов текста без жесткого ограничения длины.
   * `blank=True` — разрешает оставлять поле пустым (необязательное для заполнения).
4. **`DateTimeField(...)`:**
   * Поле для хранения даты и времени.
   * `auto_now_add=True` — автоматически записывает текущее время **только один раз** при создании записи.
   * `auto_now=True` — автоматически обновляет время **при каждом изменении** (сохранении) записи.
5. **`BooleanField(default=True)`:**
   * Логическое поле (`True` / `False`).
   * `default=True` — задает значение по умолчанию при создании новой записи.

> **Важно:** Простого объявления класса в `models.py` недостаточно для появления таблицы в базе данных. Для создания и обновления структуры таблиц в БД используется специальный механизм **миграций**.
