# Полиморфизм

✅ **Полиморфизм** — это множество форм. Однако в понятиях ООП имеется в виду скорее обратное: объекты разных классов, с разной внутренней реализацией могут иметь одинаковые интерфейсы.

✅ **Полиморфизм операторов** позволяет одному оператору (например, `+`) выполнять разные действия в зависимости от типа операндов (сложение чисел, конкатенация строк и так далее).

✅ **Полиморфизм функций** позволяет одной функции работать с объектами разных типов.

✅ **Полиморфизм в методах класса** позволяет обобщить вызов методов различных классов с одинаковыми именами, игнорируя тип объекта.
