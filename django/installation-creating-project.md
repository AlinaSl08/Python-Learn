# Шпаргалка по Django: Настройка окружения и первый запуск проекта

Краткое пошаговое руководство по развертыванию базового проекта Django в изолированном виртуальном окружении.

---

## Шаг 1. Проверка глобального окружения
Перед началом работы необходимо убедиться, что в системе установлен Python.

* **Проверить версию Python:**
  * **Windows:** `python -V`
  * **Mac / Linux:** `python3 -V`
* **Посмотреть установленные глобальные пакеты:** `pip list`

---

## Шаг 2. Создание и активация виртуального окружения (`venv`)
Виртуальное окружение необходимо для изоляции зависимостей конкретного проекта от глобальной системы.

1. **Перейти в рабочую папку проекта:**
   ```bash
   cd D:\Python\Projects\django
   ```
2. **Создать окружение с именем `djvenv`:**
   * **Windows:** `python -m venv djvenv`
   * **Mac / Linux:** `python3 -m venv djvenv`
3. **Активировать окружение:**
   * **Windows:** `.\djvenv\Scripts\activate`
   * **Mac / Linux:** `source djvenv/bin/activate`

*Признак успешной активации — появление префикса `(djvenv)` в начале строки терминала.*

* **Выйти из окружения (при необходимости):** `deactivate`

---

## Шаг 3. Установка Django
Установка фреймворка выполняется строго внутри активированного виртуального окружения.

* **Установка конкретной версии Django:**
  ```bash
  pip install django==4.2.1
  ```
* **Проверить список доступных команд ядра фреймворка:** `django-admin`

---

## Шаг 4. Создание проекта Django
Команда инициализирует базовую структуру каталогов нового сайта.

* **Создать проект:**
  ```bash
  django-admin startproject sitewomen
  ```

> 💡 **Важный нюанс (про «точку» в конце команды):**
> * **Без точки** (`django-admin startproject sitewomen`): Django создаст внешнюю папку-контейнер `sitewomen`, а внутри неё — ещё одну вложенную папку `sitewomen` с настройками. Из-за этого получается дублирование имён и лишняя вложенность.
> * **С точкой** (`django-admin startproject config .`): Django создаст файлы настроек (`settings.py`, `urls.py`) в папку `config`, а управляющий файл `manage.py` положит сразу в текущую корневую папку, без лишней вложенности.

### Основные компоненты созданной структуры:
* **Папка `sitewomen/` (внутренняя):** Пакет конфигурации сайта (файлы настроек `settings.py`, маршрутов `urls.py` и др.).
* **Файл `manage.py`:** Главная управляющая утилита проекта, выступающая посредником между разработчиком и `django-admin`.

---

## Шаг 5. Запуск отладочного веб-сервера
Локальный сервер Django автоматически отслеживает изменения в коде и перезапускается при сохранении файлов.

1. **Перейти в папку с файлом `manage.py`:**
   ```bash
   cd sitewomen
   ```
2. **Запустить сервер:**
   ```bash
   python manage.py runserver
   ```
   *Сайт по умолчанию станет доступен в браузере по адресу: http://127.0.0.1:8000*

### Полезные команды при работе с сервером:
* **Остановить сервер:** `Ctrl + C` (или `Ctrl + Break` на Windows).
* **Запустить на другом порту (например, 4000):** 
  ```bash
  python manage.py runserver 4000
  ```
* **Запустить на конкретном IP и порту:** 
  ```bash
  python manage.py runserver 192.168.1.1:4000
  ```

> 📌 **Примечание:** При первом старте сервера автоматически создается файл `db.sqlite3`. По умолчанию Django работает со встроенной базой данных **SQLite**, но также из коробки поддерживает *PostgreSQL, MariaDB, MySQL и Oracle*
