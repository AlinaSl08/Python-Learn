# Базовый синтаксис (Делимитеры)

В Jinja2 используются специальные конструкции для разделения кода разметки и логики шаблонизатора:

+ `{{ ... }}` — **Переменные и выражения**. Выводит результат вычисления (строку, число, переменную) в итоговый документ.
+ `{% ... %}` — **Инструкции (управляющие конструкции). Логика**: циклы, ветвления, макросы.
+ `{# ... #}` — **Комментарии**. Игнорируются при рендеринге шаблона

# Управление пробелами

По умолчанию Jinja сохраняет все переносы строк и пробелы вокруг тегов. Чтобы удалить их, в теги добавляется дефис -:
+ `{%- ... %}` — удаляет пробелы **слева** от блока.
+ `{% ... -%}` — удаляет пробелы **справа** от блока.
+ `{%- ... -%}` — удаляет пробелы с **обеих** сторон.

# Управляющие конструкции (Условия и Циклы)

Ветвление `if-elif-else`:

``` python
{% if user.is_authenticated %}
  <p>Привет, {{ user.username }}!</p>
{% elif user.is_guest %}
  <p>Привет, Гость!</p>
{% else %}
  <p>Пожалуйста, войдите в систему.</p>
{% endif %}
```

Цикл for.
Используется для перебора списков, кортежей и словарей:

``` python
<ul>
{% for item in items %}
  <li>{{ item }}</li>
{% else %}
  <li>Список пуст</li> <!-- Выполнится, если items пустой -->
{% endfor %}
</ul>
```

Внутри цикла `for` доступна служебная переменная `loop`, предоставляющая контекст:
+ `loop.index` — текущая итерация (отсчет с 1).
+ `loop.index0` — текущая итерация (отсчет с 0).
+ `loop.first` / `loop.last` — `True`, если итерация первая или последняя.
+ `loop.length` — общее количество элементов в цикле.

# Фильтры (Filters)

Фильтры изменяют переменные перед выводом. Они применяются через символ вертикальной черты | и могут объединяться в цепочки:
+ `{{ name | upper }}` — переводит строку в ВЕРХНИЙ РЕГИСТР.
+ `{{ text | lower }}` — переводит строку в нижний регистр.
+ `{{ text | title }}` — делает первую букву каждого слова заглавной.
+ `{{ items | length }}` — возвращает длину списка/строки.
+ `{{ value | default('Значение по умолчанию') }}` — выводит дефолтный текст, если переменная не задана.
+ `{{ html_code | safe }}` — отключает автоматическое экранирование HTML для этой переменной (выводит теги как есть).
+ `{{ my_list | join(', ') }}` — объединяет элементы списка в строку

# Наследование шаблонов (Template Inheritance)

Одна из самых мощных фич Jinja. Позволяет создать базовый каркас сайта (base.html), а в дочерних шаблонах изменять только определенные блоки.
Базовый шаблон (`base.html`):

``` html
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}Мой сайт{% endblock %}</title>
</head>
<body>
    <div id="content">
        {% block content %}{% endblock %}
    </div>
</body>
</html>
```

Дочерний шаблон (index.html):

``` python
{% extends "base.html" %} {# Наследуем базовый шаблон #}

{% block title %}Главная страница{% endblock %}

{% block content %}
    <h1>Добро пожаловать!</h1>
    <p>Это уникальный контент главной страницы.</p>
{% endblock %}
```

# Включение шаблонов (include) и Макросы

+ `include` — позволяет вставить содержимое одного шаблона внутрь другого (например, шапку `header.html` или подвал `footer.html`):

``` python
{% include 'footer.html' %}
```

+ Макросы (`macro`) — аналог функций в Python. Они позволяют переиспользовать фрагменты кода HTML:

``` python
{% macro render_input(name, value='', type='text') %}
  <input type="{{ type }}" name="{{ name }}" value="{{ value }}">
{% endmacro %}

{# Вызов макроса #}
{{ render_input('username') }}
```

# Рендеринг в Python (Интеграция)

Базовый пример компиляции шаблона из скрипта Python:

``` python
from jinja2 import Environment, FileSystemLoader

# Настройка окружения и указание папки с шаблонами
env = Environment(loader=FileSystemLoader('templates'))

# Загрузка конкретного шаблона
template = env.get_template('index.html')

# Передача данных и рендеринг в строку
data = {'user': {'username': 'Alex'}, 'items': ['Книга', 'Ручка']}
output = template.render(data)

print(output)
```
