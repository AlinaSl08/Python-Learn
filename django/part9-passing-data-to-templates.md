# Передача данных (контекста) в шаблоны Django

**Шаблон (Template)** — это HTML-документ, который описывает структуру страницы, а его наполнение происходит динамически за счет передачи данных из программы (функций представлений).

---

## 1. Синтаксис переменных в шаблонах

Для вывода переданных данных внутри HTML-шаблона используются **двойные фигурные скобки**: `{{ имя_переменной }}`.

**Пример шаблона (`index.html`):**
```html
<!DOCTYPE html>
<html>
<head>
    <title>{{ title }}</title>
</head>
<body>
    <h1>{{ title }}</h1>
</body>
</html>
```

### Важные правила синтаксиса:
* **Одна переменная — одни скобки:** Нельзя писать несколько переменных внутри одних скобок.
  * ❌ Неправильно: `{{ obj.a obj.b }}` *(вызовет ошибку)*
  * ✅ Правильно: `{{ obj.a }} {{ obj.b }}`
* **Несуществующие переменные игнорируются:** Если в шаблоне указана переменная (например, `{{ menu }}`), но она не была передана из функции представления, Django **не выдаст ошибку** — переменная просто будет проигнорирована и не отобразится на странице.

---

## 2. Передача данных из представления (`views.py`)

Данные передаются в функцию `render()` в виде **словаря** (через третий позиционный аргумент или именованный аргумент `context`). Ключи словаря становятся именами переменных в шаблоне.

```python
from django.shortcuts import render

# Вариант 1: через переменную data и именованный аргумент context
def index(request):
    data = {'title': 'Главная страница'}
    return render(request, 'women/index.html', context=data)

# Вариант 2: короткая запись (передача словаря напрямую)
def about(request):
    return render(request, 'women/about.html', {'title': 'О сайте'})
```

## 3. Работа с разными типами данных

В шаблон можно передавать любые типы данных Python: числа, строки, списки, кортежи, множества, словари и объекты пользовательских классов.

**Пример в `views.py`:**
```python
class MyClass:
    def __init__(self, a, b):
        self.a = a
        self.b = b

menu = ["О сайте", "Добавить статью", "Обратная связь", "Войти"]

def index(request):
    data = {
        'title': 'Главная страница',
        'menu': menu,
        'float': 28.56,
        'lst': [1, 2, 'abc', True],
        'set': {1, 1, 2, 3, 2, 5},
        'dict': {'key_1': 'value_1', 'key_2': 'value_2'},
        'obj': MyClass(10, 20),
    }
    return render(request, 'women/index.html', context=data)
```

## 4. Особенности обращения к элементам коллекций и объектов

Шаблонизатор Django **не поддерживает квадратные скобки `[]`** для обращения по индексу или ключу (это вызовет ошибку `TemplateSyntaxError`). Вместо этого везде используется **оператор «точка» (`.`)**.

| Тип данных | Пример в Python | Как вывести в шаблоне Django | Комментарий |
| :--- | :--- | :--- | :--- |
| **Словарь** | `dict['key_1']` | `{{ dict.key_1 }}` | ❌ `{{ dict['key_1'] }}` вызовет ошибку |
| **Объект класса** | `obj.a` | `{{ obj.a }}` | Стандартное обращение к атрибуту |
| **Список / кортеж** | `menu[0]` | `{{ menu.0 }}` *(или циклом)* | ❌ `{{ menu[0] }}` вызовет ошибку `TemplateSyntaxError` |
