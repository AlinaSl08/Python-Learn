# Декораторы

✅ **Декораторы** представляют собой инструмент, основной целью которого является расширение функционала функций.

✅ Существует два способа использования декораторов в классах:

+ декорирование методов
+ декорирование всего класса

✅ Декоратор может возвращать не только функцию, но и **вызываемый объект**, который аналогичным образом способен заменить декорируемую функцию. Данный подход позволяет реализовывать декораторы не только с помощью функций, но и с помощью классов, экземпляры которых являются вызываемыми объектами, то есть содержат магический метод `__call__()`.

✅ **Декорирование класса** позволяет модифицировать поведение и содержание класса без изменения его исходного кода.

✅ **Синтаксис** декорирования класса ничем не отличается от синтаксиса декорирования функции. Например, задекорировать класс можно одним из следующих способов:

1. 
``` python
@decorator
class MyClass:
    pass
```

2.
``` python                  
MyClass = decorator(MyClass)
```
                  
✅ **Подход декорирования** функции несколько отличается от декорирования класса. Если в первом случае мы заменяем функцию другой функцией или вызываемым объектом, то во втором случае мы модифицируем исходный класс и возвращаем его же.

✅ Декоратор класса имеет достаточно глубокие возможности влияния на класс: он может удалять, добавлять, менять, переименовывать атрибуты и методы класса. Поэтому следует понимать, что при декорировании исходный класс не всегда может быть использован так же, как прежде.
