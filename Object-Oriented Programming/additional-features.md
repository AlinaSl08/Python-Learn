# Слоты, атрибут __slots__

✅ **Слоты** позволяют оптимизировать использование памяти в Python. Если экземпляры некоторого класса содержат только фиксированный (определенный заранее) набор атрибутов, можно использовать слоты, чтобы вместо словарей использовалась более компактная структура данных.

✅ Для **реализации** слотов в Python используется атрибут **класса `__slots__`**. С помощью данного атрибута мы определяем набор атрибутов, которыми может обладать экземпляр класса. После определения слотов в классе Python **не будет** использовать словарь `__dict__` для управления атрибутами экземпляров этого класса. Также пропадет возможность добавлять экземплярам класса новые атрибуты.

✅ **Значением** атрибута `__slots__` может быть любой итерируемый объект, однако на практике используют **кортеж**.

✅ Если родительский класс имеет слоты, а дочерний класс не имеет, экземпляры последнего будут иметь словарь атрибутов `__dict__`. Таким образом, дочерний класс будет использовать как слоты из родительского класса, так и словарь атрибутов `__dict__`.

✅ Если родительский класс не использует слоты, а дочерний класс использует, экземпляры дочернего класса все равно будут иметь словарь атрибутов `__dict__`.

✅ Класс с использованием слотов в среднем на `15-20 %` **быстрее** в операциях доступа к атрибутам. Экземпляры классов с использованием слотов занимают **меньше** памяти, чем экземпляры классов без использования слотов.

# Перечисления, класс Enum

✅ **Перечисление** — это набор символических имен, привязанных к уникальным постоянным значениям.

✅ В Python **для создания** перечислений используется **класс `Enum`** из модуля `enum`. Чтобы создать собственное перечисление, можно либо создать подкласс `Enum`, либо использовать его функциональную часть.

✅ При создании **подкласса** `Enum` каждый элемент перечисления получает имя и уникальное значение:

``` python
from enum import Enum

class MyEnum(Enum):
    NAME_1 = <value_1>
    NAME_2 = <value_2>
```
                  
Элементы перечисления являются функциональными константами и представляют собой экземпляры класса перечисления. Они имеют атрибуты `name` и `value`, в которых содержатся их имена и значения соответственно. Зачастую элементы перечислений принимают последовательные целочисленные значения, однако они могут быть **любыми** и принадлежать **любому типу**.

✅ Создание перечислений с помощью **функциональной части** класса `Enum` подразумевает вызов Enum с соответствующим набором аргументов. В качестве первого аргумента необходимо указать имя класса перечисления, а в качестве второго — имена элементов перечисления (любой итерируемый объект или строка, в которой имена разделены одним пробелом):

``` python
from enum import Enum

MyEnum = Enum('MyEnum', ['NAME_1', 'NAME_2'])
```
                  
или:

``` python
from enum import Enum

MyEnum = Enum('MyEnum', 'NAME_1 NAME_2')
```
                  
По умолчанию элементы перечисления принимают последовательные целочисленные значения, начиная с `1`. Это поведение можно изменить, передав при создании необязательный аргумент `start`, который определяет начальное значение. Также в качестве второго аргумента — имен элементов перечисления — можно передать итерируемый объект, в котором представлены пары **имя — значение** (список кортежей или аналогичный словарь): 

``` python
from enum import Enum

MyEnum = Enum('MyEnum', [('NAME_1', <value_1>), ('NAME_2', <value_2>)])
```
                  
или:

``` python
from enum import Enum

MyEnum = Enum('MyEnum', {'NAME_1': <value_1>, 'NAME_2': <value_2>})
```
                  
✅ Поскольку перечисления используются для представления констант, изменение значений их элементов **невозможно** и приводит к возбуждению исключения.

✅ **Доступ** к элементам перечисления:

``` python
MyEnum.NAME          # точечная нотация с указанием имени элемента
MyEnum['NAME']       # доступ по ключу в виде имени элемента
MyEnum(<value>)      # вызов перечисления с аргументом в виде значения элемента
```
                  
✅ Перечисления являются **итерируемыми объектами**, поэтому мы можем перебирать их в цикле или преобразовывать в коллекции. Элементы перечисления при итерировании располагаются в том порядке, в котором они были определены в классе.

✅ Перечисления поддерживают два вида сравнения:

+ сравнение **на равенство** с помощью операторов `==` и `!=`
+ сравнение **на идентичность** с помощью операторов `is` и `is not`

✅ По умолчанию перечисления **не поддерживают** операции сравнения с помощью операторов `>, <, >= и <=`, поэтому для их сортировки необходимо использовать **ключевую функцию**.

✅ Все перечисления (наследники класса `Enum`) имеют следующие **магические методы**:

+ `__contains__()`
+ `__getitem__()`
+ `__iter__()`
+ `__len__()`
+ `__reversed__()`

✅ Если значениями элементов перечисления являются последовательные целые числа, начиная с `1`, мы можем не прописывать их явно, а воспользоваться **функцией `auto()`** из модуля `enum`.

# Битовые флаги, класс Flag

✅ С помощью **класса `Flag`** модуля `enum` можно создавать **битовые флаги**. Битовые флаги похожи на перечисления, однако в отличие от перечислений элементы флагов поддерживают битовые операции с помощью **операторов `|`** (побитовое ИЛИ), **`&`** (побитовое И), **`^`** (побитовое исключающее ИЛИ) и **`~`** (побитовое НЕ).

✅ Для того чтобы битовые операции выполнялись корректно, значениями элементов флага должны являться **степени двойки**.

✅ **Оператор `|`** позволяет объединить элементы флага.

✅ **Оператор `^`** позволяет исключить один или несколько элементов из объединения элементов.

✅ **Оператор `&`** позволяет получить общие элементы из нескольких объединений элементов.

✅ **Оператор `~`** позволяет получить все элементы флага, кроме заданных.

✅ **Объект**, полученный в результате какой-либо битовой операции между элементами флага, сам является **элементом флага**. Если он не является фактическим элементом флага (определенным внутри класса), то у него нет имени, однако есть значение.

✅ В результате битовых операций с элементами флага может получиться элемент с **нулевым значением**. Ошибки в данном случае не произойдет, так как флаг для подобных ситуаций автоматически определяет элемент с именем `None` и значением `0`.

✅ **Проверить наличие** одного или нескольких элементов в объединении элементов можно с помощью **оператора `in`**.

✅ Битовые флаги имеют **весь функционал** обычных перечислений: доступ к элементам, итерирование, сравнение на равенство и идентичность и так далее.

✅ Для **автоматической** установки в качестве значений элементам флага степеней двойки можно использовать **функцию `auto()`**.
