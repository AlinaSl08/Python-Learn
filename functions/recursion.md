# Рекурсия

✅ **Рекурсивная функция** – это функция, которая вызывает саму себя.

✅ **Рекурсивная функция** работает следующим образом:

+ если в настоящий момент задача может быть решена без рекурсии, то функция ее решает
+ если в настоящий момент задача не может быть решена, то функция сводит ее к уменьшенной и при этом аналогичной задаче и вызывает саму себя для решения этой уменьшенной задачи

Для того чтобы применить такой подход, во-первых, нужно идентифицировать по крайней мере один случай, в котором задача может быть решена без рекурсии. Он называется **базовым случаем**. Во-вторых, нужно определить то, как задача будет решаться рекурсивно во всех остальных случаях. Это называется **рекурсивным случаем**. В рекурсивном случае задача сводится к уменьшенному варианту исходной задачи. С каждым рекурсивным вызовом задача уменьшается. В результате будет достигнут базовый случай, и рекурсия прекратится.

✅ **Глубина рекурсии** – количество раз, которое функция вызывает саму себя.

✅ **Хвостовая рекурсия** — частный случай рекурсии, при котором любой рекурсивный вызов является последней операцией перед возвратом из функции.

✅ **Мемоизация** – это способ оптимизации, при котором результат выполнения функции сохраняется и используется при следующем вызове.

✅ **Мемоизация** присутствует по умолчанию во многих функциональных языках программирования. В Python включать такой функционал надо вручную (декоратор `lru_cache`).

✅ **Рекурсию** также можно использовать в лямбда-функциях.
