# Атрибуты объектов и классов

✅ Для получения списка всех **атрибутов и методов** объекта можно воспользоваться **встроенной функцией `dir()`**.

✅ В Python **классы создаются** с помощью инструкции **`class`**, за которой следует имя класса, после которого ставится двоеточие. Далее с новой строки и с отступом реализуется тело класса:
``` python
class <название класса>:
    <тело класса>
```
                  
Как правило, имя класса начинается с заглавной буквы и обычно является существительным или словосочетанием. Имена классов соответствуют соглашению **Upper Сamel Сase**.

✅ Чтобы **создать объект** класса, нужно воспользоваться следующим синтаксисом:
``` python
<имя переменной> = <имя класса>()
```
                  
Объект класса также называют **экземпляром класса.**

✅ С помощью точечной нотации экземпляр класса можно наделять различными атрибутами, обращаться к установленным атрибутам, а также изменять их. При обращении к несуществующему атрибуту будет возбуждено исключение **`AttributeError`**.

✅ Устанавливать атрибуты также можно на уровне всего класса, такие атрибуты называются **атрибутами класса**. Их значения одинаковы для всех экземпляров этого класса. Получить к ним доступ можно, используя точечную нотацию с именем класса.

✅ Как правило, названия атрибутов объектов и классов пишутся с маленькой буквы и соответствуют соглашению **snake case**.

✅ Все атрибуты, которыми мы наделяем созданные объекты, хранятся в специальном словаре, который доступен в качестве **атрибута `__dict__`**. Аналогичным образом можно получить доступ к атрибутам класса.

✅ Атрибуты объектов и классов, которые определил программист, называются **пользовательскими атрибутами**.

✅ **Функция `getattr()`** принимает три аргумента:

+ `obj` — объект
+ `name` — имя атрибута
+ `default` — значение по умолчанию

Функция возвращает значение атрибута name объекта `obj`. Если объект `obj` не имеет атрибута `name`, возвращается значение по умолчанию `default`. Если значение по умолчанию не указано, возбуждается исключение `AttributeError`. Так же, как и через точечную нотацию, с помощью функции `getattr()` можно получать значения атрибутов класса через экземпляры этого класса.

✅ ​​​​​​​Функция setattr() принимает три аргумента:

obj — объект
name — имя атрибута
value — значение атрибута
Функция устанавливает объекту obj атрибут name со значением value. Если объект obj уже имеет атрибут name, его значение перезаписывается.

✅ **Функция `delattr()`** принимает два аргумента:

+ `obj` — объект
+ `name` — имя атрибута

Функция удаляет атрибут `name` у объекта `obj`. Если объект не имеет атрибута `name`, возбуждается исключение `AttributeError`.

✅ **Функция `hasattr()`** принимает два аргумента:

+ `obj` — объект
+ `name` — имя атрибута

Функция возвращает `True`, если объект `obj` имеет атрибут `name`, или `False` в противном случае.

# Методы экземпляра класса

✅ **Метод экземпляра** — это функция, которая определена внутри класса, принадлежит объекту этого класса и имеет доступ к атрибутам объекта.

✅ Каждый метод имеет **параметр `self`**. Когда метод вызывается, параметр `self` в качестве аргумента принимает тот экземпляр, через который этот метод был вызван. Именно этим экземпляром метод и будет оперировать. Параметр `self` часто называют **контекстным объектом**. Параметр `self` — это обычная переменная, она может называться по-другому, но так **категорически** не рекомендуется делать.

✅ **Метод `__init__()`** называют **методом инициализации** или **инициализатором**. Метод `__init__()` инициализирует атрибуты объекта. Сразу после создания объекта исполняется метод `__init__()`, и параметру `self` автоматически присваивается объект, который был только что создан, что позволяет тут же наделить его необходимыми атрибутами.

✅ Класс может иметь только один инициализатор. При попытке определить в классе два инициализатора предыдущий будет **заменен** следующим.

✅ **Применение метода** к объекту преобразуется в вызов функции путем обращения к ней через соответствующий класс и передачи ей в качестве аргумента объекта, который этот метод вызвал.

# Модификаторы доступа и аксессоры

✅ **В классических языках** программирования (C++, Java, C#) доступ к атрибутам реализуется с помощью ключевых слов `public` (публичный), `protected` (защищенный) и `private` (приватный):

+ публичные атрибуты доступны для работы вне класса
+ доступ к защищенным атрибутам возможен только внутри текущего класса, а также внутри унаследованных от него классов
+ приватные атрибуты недоступны извне — с ними можно работать только внутри текущего класса

✅ В Python **отсутствует** механизм, который мог бы запретить внешнему коду взаимодействовать с атрибутами объекта или класса. Вместо этого создатели Python предложили следующий ряд соглашений:

+ если имя атрибута начинается с одного нижнего подчеркивания (`_name`), то он считается **защищенным**
+ если имя атрибута начинается с двух нижних подчеркиваний (`__name`), то он считается **приватным**

✅ В Python все атрибуты являются публичными по умолчанию. Любой атрибут объекта **может быть доступен** за пределами класса, независимо от того, является он публичным, защищенным или приватным:

+ публичные атрибуты доступны вне класса
+ защищенные атрибуты не предназначены для прямого использования вне класса, но все еще доступны
+ приватные атрибуты становятся недоступны **напрямую** извне за счет механизма **искажения имени**, но возможность обратиться к приватному атрибуту, а также изменить его значение все же остается

✅ **Физически механизм** ограничения доступа к атрибутам в Python реализован слабо, лишь на уровне соглашения, поэтому ответственность за соблюдение данного соглашения ложится на плечи программистов. Защищенные атрибуты помогают указать, что их изменение может нарушить логику работы класса, но не накладывают строгих ограничений.

✅ **Геттер** — это метод, который возвращает значение атрибута и при этом не изменяет его. Геттеры дают возможность программному коду, находящемуся за пределами класса, получать значения атрибутов безопасным способом, не подвергая эти атрибуты изменению программным кодом, находящимся вне метода.

✅ **Сеттер** — это метод, который сохраняет значение в атрибуте либо изменяет значение атрибута. Сеттеры могут управлять тем, как атрибуты объекта изменяются. Когда программный код, находящийся вне класса, должен изменить в объекте значение атрибута, он, как правило, вызывает сеттер и передает новое значение в качестве аргумента. Если это необходимо, то метод, прежде чем он присвоит значение атрибуту, может выполнить проверку этого значения.

✅ **Делитер** — это метод, который удаляет атрибут из объекта.
