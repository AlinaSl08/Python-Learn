# Формат JSON

✅ **JSON** (англ. JavaScript Object Notation) — текстовый формат обмена данными, основанный на языке программирования JavaScript. Как и многие другие текстовые форматы, `json` легко читается людьми.

✅ Преобразование переменных программы (Python-объектов) в формат для хранения называется **сериализацией**, а обратное преобразование — **десериализацией**.

✅ **Модуль `json`** предназначен для **сериализации** и **десериализации** данных в формат `json`.

✅ **Функция `dumps()`** используется для сериализации данных. Она принимает на вход любой сериализуемый Python-объект (например, словарь, список, числа, строки) и возвращает в **`json`-строку**.

✅ **Функция `dump()`** выполняет сериализацию данных и **записывает результат в файл**. Она принимает два аргумента: сериализуемый Python-объект и файловый объект.

✅ **Функции `dumps()` и `dump()`** имеют необязательные аргументы:

+ `indent` задает отступ от левого края, по умолчанию имеет значение `None`
+ `sort_keys` задает сортировку ключей в результирующем json, по умолчанию имеет значение `False`
+ `separators` задает кортеж, состоящий из двух элементов `(item_separator, key_separator)`, которые представляют разделители для элементов и ключей, по умолчанию имеет значение `(', ', ': ')`

✅ **Функция `loads()`** принимает **строку** с данными в формате `json` и возвращает ее десериализованное содержимое — соответствующий Python-объект.

✅ **Функция `load()`** принимает **файловый объект**, содержащий данные в формате `json`, и возвращает его десериализованное содержимое — соответствующий Python-объект.

✅ **Модуль `json`** автоматически определяет тип значения при десериализации.

✅ **Таблица** конвертации типов данных Python в `json`:

|Python|	json|
|:--:|:--:|
|dict|	object|
|list, tuple|	array|
|str|	string|
|int, float|	number|
|True|	true|
|False|	false|
|None|	null|

✅ **Таблица** конвертации `json` в **типы данных Python**:

|json|	Python|
|:--:|:--:|
|object|	dict|
|array|	list|
|string	|str|
|number (int)|	int|
|number (real)|	float|
|true	|True|
|false|	False|
|null|	None|
