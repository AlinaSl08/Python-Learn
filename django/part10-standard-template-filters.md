# Фильтры (Filters) в шаблонах Django

**Фильтры** позволяют преобразовывать значения переменных прямо внутри HTML-шаблонов перед их выводом на страницу.

* Официальная документация: [Built-in template tags and filters](https://docs.djangoproject.com/en/4.2/ref/templates/builtins/).

---

## 1. Синтаксис фильтров

Фильтр применяется к переменной через вертикальную черту (`|`). Если фильтру нужен аргумент, он указывается после двоеточия (`:`) в кавычках.

```html
<!-- Без аргумента -->
{{ переменная|имя_фильтра }}

<!-- С аргументом -->
{{ переменная|имя_фильтра:"аргумент" }}

<!-- Цепочка фильтров (применяются последовательно слева направо) -->
{{ title|cut:" "|cut:"?" }}
```

---

## 2. Основные встроенные фильтры

| Фильтр | Описание | Пример в шаблоне | Результат |
| :--- | :--- | :--- | :--- |
| **`add`** | Прибавляет целое число (дробная часть отбрасывается). | `{{ float\|add:"50" }}` *(если `float = 28.56`)* | `78` |
| **`capfirst`** | Делает первый символ строки заглавным. | `{{ title\|capfirst }}` *(если `title = 'главная'`)* | `Главная` |
| **`upper`** | Переводит все символы строки в верхний регистр. | `{{ title\|upper }}` | `ГЛАВНАЯ` |
| **`lower`** | Переводит все символы строки в нижний регистр. | `{{ title\|lower }}` | `главная` |
| **`cut`** | Удаляет все вхождения указанной подстроки. | `{{ title\|cut:" " }}` | Удалит все пробелы |
| **`default`** | Подставляет значение по умолчанию, если переменная пустая, равна `False` или не передана. | `{{ main_title\|default:"Без заголовка" }}` | `Без заголовка` *(если пусто)* |
| **`divisibleby`** | Проверяет делимость числа на аргумент (`True` / `False`). | `{{ float\|divisibleby:"2" }}` *(для `28.56`)* | `True` *(проверяет целую часть `28`)* |
| **`first`** | Возвращает первый элемент списка или кортежа. | `{{ menu\|first }}` | `О сайте` |
| **`last`** | Возвращает последний элемент списка или кортежа. | `{{ menu\|last }}` | `Войти` |
| **`join`** | Объединяет элементы коллекции в строку через разделитель. | `{{ menu\|join:" \| " }}` | `О сайте \| Добавить статью \| ...` |
| **`length`** | Возвращает длину коллекции или строки (аналог `len()`). | `{{ lst\|length }}` | Количество элементов |
| **`slugify`** | Преобразует строку в URL-слаг (строчные латинские буквы, цифры и дефисы). | `{{ "The Main Page"\|slugify }}` | `the-main-page` |

---

## 3. Использование фильтров в Python-коде (`views.py`)

Любой встроенный фильтр шаблонов можно импортировать и использовать как обычную функцию прямо в коде программы на Python из модуля **`django.template.defaultfilters`**.

**Пример (`views.py`):**
```python
from django.shortcuts import render
from django.template.defaultfilters import slugify

def index(request):
    data = {
        'title': 'главная страница',
        'url': slugify("The main page"),  # Преобразуем строку заранее в Python
    }
    return render(request, 'women/index.html', context=data)
```

**Вывод в шаблоне (`index.html`):**
```html
<p>{{ url }}</p> <!-- Выведет: the-main-page -->
```
