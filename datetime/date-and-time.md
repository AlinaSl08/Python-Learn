# Модуль datetime

✅ **Модуль `datetime`** используется для работы с временем и датами, позволяя представлять эту информацию в удобной форме.

✅ **Типы данных** модуля `datetime`:

|Название типа данных|	Характеристика|
|:--:|:--:|
|`date`|	представляет собой информацию о дате, исключая данные о времени, на основе григорианского календаря|
|`time`|представляет собой информацию о времени, полностью исключая сведения о дате|
|`datetime`|	содержит информацию о времени и дате, основываясь на данных из григорианского календаря|
|`timedelta`|	описывает определенный период во времени, который находится между двумя различными моментами|
|`tzinfo`|	представляет различные сведения о часовом поясе|
|`timezone`|	описывает время, руководствуясь стандартом UTC|


✅ **Тип данных `date`**:

+ При создании новой даты (тип данных `date`) нужно указать год, месяц и день:
``` python
from datetime import date

my_date = date(<year>, <month>, <day>)
```
                  
+ Доступ к атрибутам:

``` python
my_date.year
my_date.month
my_date.day
```
                  
+ Для получения текущей даты используется метод `today()`:

``` python
from datetime import date

date.today()
```
                  
+ Для определения дня недели используются методы `weekday()` и `isoweekday()`:
``` python
my_date.weekday()      # Пн - 0, Вс - 6
my_date.isoweekday()   # Пн - 1, Вс - 7
```                
+ Для получения минимально и максимально возможных дат используются атрибуты `min` и `max`:
``` python
from datetime import date

min_date = date.min
max_date = date.max
```
                  
+ Методы `fromordinal() и toordinal()` позволяют создать дату из номера дня, начиная с `0001-01-01`, и наоборот — преобразовать дату в номер дня:
``` python
from datetime import date

date.fromordinal(n)      # дата, соответствующая номеру дня n
my_date.toordinal()      # номер дня, соответствующий дате my_date
```
                  
✅ **Тип данных `time`**:

+ При создании времени (тип данных time) нужно указать часы, минуты, секунды и микросекунды (недостающие данные о времени автоматически заполняются нулями):
``` python
from datetime import time

my_time = time(<hour>, <minute>, <second>, <microsecond>)
```
                  
+ Доступ к атрибутам:
``` python  
my_time.hour
my_time.minute
my_time.second
my_time.microsecond
```
                  
✅ Даты (тип `date`) и время (тип `time`) можно **сравнивать** с помощью операторов `==, !=, <, >, <= и  >=`.

✅ **Встроенная функция `str()`** возвращает объект в **неформальном (понятном человеку)** строковом представлении.

✅ **Встроенная функция `repr()`** возвращает объект в **формальном (понятном интерпретатору)** строковом представлении.

✅ Типы данных `date` и `time` являются **неизменяемыми**.

✅ По умолчанию объекты типов `date` и `time` выводятся в формате **ISO 8601**:

+ дата в формате ISO 8601 имеет следующий вид: `YYYY-MM-DD`
+ время в формате ISO 8601 имеет следующий вид: `HH:MM:SS или HH:MM:SS.ffffff`
