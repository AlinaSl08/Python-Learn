# Регулярные выражения

✅ **Регулярные выражения** (regular expression, regex, регулярка) – это мощный способ обработки текста, позволяющий находить в строках подстроки по сложным условиям. Чуть более формально, **регулярное выражение** — это строка, задающая шаблон поиска подстрок в тексте. Регулярное выражение состоит из обычных символов и специальных командных последовательностей.

✅ **Регулярные выражения** обычно применяют в следующих сценариях:

+ поиск подстрок в строке
+ разделение строки на подстроки
+ замена части строки

✅ В языке Python некоторые символы нужно **экранировать**, чтобы они воспринимались правильно. К таким символам относятся:

+ обратный слеш `\`
+ одинарная кавычка `'`
+ двойная кавычка `"`
+ и многие другие

✅ **Экранированные последовательности** — это последовательности, которые начинаются с символа `\`, за которым следует один или более символов (`\\, \', \", \n, \t` и так далее).

✅ **Сырые строки** — это строки, в которых каждый символ интерпретируется буквально, как он написан. Чтобы создать сырую строку в Python, перед открывающей кавычкой добавляется буква `r`.

✅ Регулярные выражения являются **регистрозависимыми**.

✅ **Метасимволы** — это специальные символы (или наборы символов), используемые в регулярных выражениях для задания шаблонов поиска.

✅ **Символ точки `.`** соответствует одному любому символу.

✅ Для поиска любой **цифры** от 0 до 9 используется **метасимвол `\d`**.

✅ Для поиска любого **нецифрового** символа используется **метасимвол `\D`**.

✅ Для поиска **пробельного** символа (пробел, табуляция, конец строки) используется **метасимвол `\s`**.

✅ Для поиска любого **непробельного** символа используется **метасимвол `\S`**.

✅ Для поиска **букв** (в верхнем и нижнем регистре), цифр и **символа подчеркивания `_`** используется **метасимвол `\w`**.

✅ Для поиска символов, **не являющихся** буквой, цифрой и подчеркиванием, используется **метасимвол `\W`**.

✅ **Метасимволы `[` и `]`** определяют набор допустимых символов, соответствие с одним из которых нужно найти.

✅ **Метасимвол дефиса `-`** используется для указания диапазона символов.

✅ **Метасимвол `^`** используется для указания соответствия **с чем угодно кроме** того, что указано в наборе символов. Он отрицает **все** символы или диапазоны в наборе, а не только символ или диапазон, которому он предшествует.

✅ **Вертикальная черта `|`** — это метасимвол, который используется для разделения нескольких шаблонов в регулярном выражении.

✅ **Таблица** соответствия некоторых метасимволов и диапазонов:

|Метасимвол|Диапазон|Описание|
|:--:|:--:|:--:|
|`\d`|	`[0-9]`|	любая цифра|
|`\D`|	`[^0-9]`|	любой нецифровой символ|
|`\w`|	`[0-9a-zA-Zа-яА-ЯёЁ_]`|	любой алфавитно-цифровой символ и символ `_`|
|`\W`|	`[^0-9a-zA-Zа-яА-ЯёЁ_]`|	любой символ, отличный от алфавитно-цифрового и `_`|
|`\s`|	`[ \f\n\r\t\v]`|	любой пробельный символ|
|`\S`|	`[^ \f\n\r\t\v]`|	любой непробельный символ|
