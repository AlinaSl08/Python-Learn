# Слоты, атрибут __slots__

✅ **Слоты** позволяют оптимизировать использование памяти в Python. Если экземпляры некоторого класса содержат только фиксированный (определенный заранее) набор атрибутов, можно использовать слоты, чтобы вместо словарей использовалась более компактная структура данных.

✅ Для **реализации** слотов в Python используется атрибут **класса `__slots__`**. С помощью данного атрибута мы определяем набор атрибутов, которыми может обладать экземпляр класса. После определения слотов в классе Python **не будет** использовать словарь `__dict__` для управления атрибутами экземпляров этого класса. Также пропадет возможность добавлять экземплярам класса новые атрибуты.

✅ **Значением** атрибута `__slots__` может быть любой итерируемый объект, однако на практике используют **кортеж**.

✅ Если родительский класс имеет слоты, а дочерний класс не имеет, экземпляры последнего будут иметь словарь атрибутов `__dict__`. Таким образом, дочерний класс будет использовать как слоты из родительского класса, так и словарь атрибутов `__dict__`.

✅ Если родительский класс не использует слоты, а дочерний класс использует, экземпляры дочернего класса все равно будут иметь словарь атрибутов `__dict__`.

✅ Класс с использованием слотов в среднем на `15-20 %` **быстрее** в операциях доступа к атрибутам. Экземпляры классов с использованием слотов занимают **меньше** памяти, чем экземпляры классов без использования слотов.
