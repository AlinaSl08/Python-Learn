✅ **В Python нет переменных** как таковых, вместо них **имена**. Имя указывает на объект и не владеет областью памяти напрямую.

✅ **Идентификатор объекта** – это целое и постоянное число, которое никогда не изменяется после его создания. В стандартной реализации Python (CPython) идентификатор объекта ассоциируется с адресом объекта в памяти.

✅ **Функция `id()`** возвращает идентификатор объекта.

✅ **Оператор `is`** сравнивает объекты на идентичность. Под идентичностью объектов подразумевается равенство их идентификаторов.

✅ **Интернирование** – это процесс хранения в памяти только одной копии объекта.

✅ Python интернирует целые числа в диапазоне от `−5 до 256`.

✅ В Python 3.7 интернируются строки, содержащие не более 20 символов и состоящие только из ASCII-букв, цифр и знаков подчеркивания. Начиная с Python 3.8 длина интернируемых строк была увеличена до `4096` символов.

✅ **Функция `intern()`** из модуля sys позволяет интернировать любую строку. Данная функция принимает в качестве аргумента строку, добавляет ее в пул интернирования (если ее там нет) и возвращает интернированную строку.

✅ Основные **преимущества** интернирования:

+ **экономия памяти**: мы не храним копии одинаковых объектов
+ **быстрые сравнения**: сравнение интернированных строк происходит намного быстрее, чем неинтернированных. Это происходит потому, что для интернированных строк нужно только сравнить, совпадают ли их адреса в памяти, а не сравнивать их содержимое
